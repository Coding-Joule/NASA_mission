# Assets: pictures the game needs

Put each picture in this folder with **exactly** the file name below.
The game finds it automatically. Until a picture is added, the game shows a
dashed box with its name, so nothing breaks.

- Use **.png** or **.jpg**. Both work.
- File names must be **all lowercase** (`mars.png`, not `Mars.PNG`). GitHub Pages cares about this.
- Drawings look best with a **transparent background** (save as .png).
- The game background is dark navy, so dark or black backgrounds on NASA photos are fine.
